# Hi, I'm Avnish Raj

I'm the creator of [Lifeline](https://github.com/AvnishR4j/lifeline), an open-source CLI that keeps AI-assisted development moving when a coding agent reaches its usage limit.

## Lifeline

Lifeline runs Claude Code, Codex, or Gemini under protection. If the active AI reaches a usage limit, Lifeline captures the relevant session and opens another supported CLI with useful context already loaded.

- Native support for Claude Code, Codex, and Gemini CLI
- Automatic usage-limit detection and cross-provider handoff
- Support for macOS, Windows, Linux, and WSL
- Available on [PyPI](https://pypi.org/project/lifeline/)

```bash
pip install --upgrade lifeline
lifeline doctor
lifeline codex
```
